# Serverpod API

1. Complete the [local database and configuration setup](../docs/development/server.md).
2. From this package, run `serverpod start` to launch the API and Flutter companion.
3. Run `dart test` here. Tests use their own embedded database.

The [notebook worker](../poodle_worker/README.md) starts separately. See [AGENTS.md](../AGENTS.md) for the project's generation, migration, and runtime workflow.
