# Poodle TDD Resources

## Knowledge

- [Flutter: An introduction to widget testing](https://docs.flutter.dev/cookbook/testing/widget/introduction)
  Primary framework documentation for `testWidgets`, `pumpWidget`, finders, and matchers. Read alongside the first splash-screen exercise. Checked 2026-10-14; the page describes Flutter 3.47, while Poodle declares Flutter ^3.44.4.
- [Martin Fowler: Test Driven Development](https://martinfowler.com/bliki/TestDrivenDevelopment.html)
  A practitioner's explanation of test first, passing implementation, and refactoring. Use to understand the development cycle; select and implement one behavior at a time.
- [Flutter: Adding a splash screen to your Android app](https://docs.flutter.dev/platform-integration/android/splash-screen)
  Primary documentation for the native launch screen and its handoff to Flutter. Use when extending the widget exercise to the experience before the first Flutter frame.

- [Serverpod: Migrations](https://docs.serverpod.dev/concepts/data-and-the-database/database/migrations)
  Primary documentation for saved schema revisions, applying changes, and repairing drift. Read with lesson 0002. Checked 2026-10-22.
- [Serverpod: Running your server](https://docs.serverpod.dev/concepts/server-fundamentals/running-your-server)
  Primary documentation for the interactive development session and migration/restart shortcuts. Checked 2026-10-22; documentation version 4.0.0.
