Poodle · Quick reference

Models → migrations → tables

TermMeaning
ModelThe .spy.yaml description of data.
Target schemaThe tables, columns, and constraints the generated application expects.
MigrationA saved set of SQL operations advancing the database schema.
ApplyExecute a migration against a particular database.
RepairReconcile an actual database with the saved migration schema after drift.

Choose the missing step

  • New model tables absent from saved migrations: create a normal migration.
  • A saved migration has not run on this database: apply pending migrations.
  • The database differs from the already applied saved schema: investigate drift and consider repair.

Read the official migration guide for the comparison and repair rules.

Interactive development session

In serverpod start, lowercase m creates and applies a normal migration; a retries pending application; r restarts in default watch mode; h shows help. See official keyboard shortcuts.

For Poodle’s course warning, inspect the migration history first. A repair cannot substitute for an unsaved course migration.
