# Mission: Build Poodle with tests first

## Why
Learn to build each screen of this Flutter and Serverpod app myself, starting with the splash screen. Use a small failing test to guide each change so I can explain what the screen promises and prove that it works.

## Success looks like
- Write a widget test for one visible screen behavior before implementing it.
- Recognize an expected assertion failure and distinguish it from a setup error.
- Make the smallest change that passes, then review the code while keeping tests green.

## Constraints
- Learn through short exercises using the actual Poodle files.
- The learner writes the app code; the agent supplies guidance and feedback.
- Keep Serverpod for backend and authentication work, following AGENTS.md.

## Out of scope
- No additional exclusions stated by the learner.
